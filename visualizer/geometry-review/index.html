What changed

Encoding, without simplification.

GLB buffer views use Meshopt compression, followed by gzip. Existing vertices, index order, normals, UVs, materials and transforms are preserved. Ground arrays and metadata use lossless gzip. Textures retain their original pixels.

Decoded geometry and GPU memory are essentially unchanged. This round targets stored and downloaded bytes. Visibility-based unloading and faster scene preparation remain separate work.

Package totals include assets beyond the selected district. Historical authoring exports are excluded from the ground review package and remain in the source snapshot. The whole-city option uses the existing overview mesh; district views load original detail tiles and landmarks.
